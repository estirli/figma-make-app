# figma-make-app


A React + Vite + Tailwind CSS application for Figma Make, ready to deploy to Vercel.

## Quick Start

```bash
pnpm install
pnpm dev
```

Visit `http://localhost:8443` to see the app.

## Build

```bash
pnpm build
```

## Deploy to Vercel

1. Connect this repository to Vercel
2. Vercel will auto-detect Vite and build accordingly
3. Your app will be deployed!

## Project Structure

- `src/main.tsx` - React entry point
- `src/App.tsx` - Main application component
- `src/index.css` - Global styles with Tailwind CSS v4
- `vite.config.ts` - Vite configuration
- `vercel.json` - Vercel deployment configuration

## Tech Stack

- **React 19** - UI library
- **Vite 8** - Build tool
- **Tailwind CSS v4** - Styling
- **TypeScript 5.7** - Type safety
- **Supabase** - Backend services (optional)
